# Securing LangGraph Agents in Production: Adversarial Evals, Runtime Detection, and Compliance Evidence

LangGraph has become a strong foundation for stateful agent workflows: agents with memory, tools, supervisors, retries, streaming output, and multi-step control flow. That power also changes the security model. A production LangGraph agent is not a single model call. It is a system that receives untrusted input, touches tools, mutates state, streams output, and often leaves behind audit obligations.

ProofLayer v0.2.0 adds a first-class LangGraph integration to `prooflayer-rules`, keeping everything inside the existing Apache-2.0 package. The goal is simple: let teams wrap a compiled LangGraph with runtime security, run adversarial evals against it, and emit compliance evidence that points back to concrete detection rules.

## The Three-Line Wrapper

The integration starts with the compiled graph customers already have:

```python
from prooflayer.integrations.langgraph import SecurityConfig, SecurityMiddleware

middleware = SecurityMiddleware(SecurityConfig(prompt_injection="block"))
secured_graph = middleware.wrap(graph.compile())
result = secured_graph.invoke({"input": user_input})
```

The secured graph preserves the normal LangGraph interface: `invoke`, `ainvoke`, `stream`, `astream`, `stream_events`, and `astream_events`.

## What ProofLayer Checks

The wrapper brings the existing ProofLayer rules engine onto the LangGraph hot path and adds agent-specific checks:

- prompt injection
- jailbreaks
- tool abuse
- input and output exfiltration
- scope drift
- state manipulation
- multi-turn slow-burn attacks
- streaming output filtering

Tool nodes can call `middleware.hooks.on_tool_call()` for allowlist enforcement and argument inspection. Supervisor and memory nodes can call `middleware.hooks.on_state_update()` to inspect state changes before they land.

## Complementary to LangSmith

ProofLayer is built to sit beside LangSmith as a complementary security layer.

| Layer | What it does | Provided by |
|---|---|---|
| Agent orchestration | Build, deploy, run agents | LangGraph |
| Tracing + observability | See what agents did | LangSmith |
| Generic evals | LLM-as-judge, regression tests | LangSmith |
| Adversarial evals | GARAK / PromptFoo red-team probes | ProofLayer |
| Runtime security | Real-time prompt injection, tool abuse, exfil detection + blocking | ProofLayer |
| Compliance evidence | NIST AI RMF / EU AI Act / SOC 2 / HIPAA audit-defensible reports | ProofLayer |

Tracing tells you what happened. ProofLayer focuses on preventing unsafe actions, probing adversarial behavior, and creating evidence records for security review.

## Adversarial Evals

v0.2.0 introduces `prooflayer.evals`, with:

- a 30-probe LangGraph adversarial suite
- a GARAK Docker runner
- a PromptFoo Docker runner
- a LangGraph target adapter
- JSON and Markdown findings reports

The local suite runs without external model credentials, which makes it useful for CI smoke tests and examples. GARAK and PromptFoo are available when teams have an OpenAI-compatible endpoint exposed for deeper red-team coverage.

## Compliance Evidence

Runtime security is more useful when events are defensible. ProofLayer emits evidence records with:

- timestamp
- source event
- framework name
- control ID
- evidence type
- previous hash
- evidence hash

The packaged registries cover AI-applicable subsets of:

- NIST AI RMF
- EU AI Act Articles 13-15
- SOC 2 CC6/CC7
- HIPAA Security Rule

Evidence is mapped conservatively. If an event category is unknown, ProofLayer emits no compliance claim.

## Performance

The rules layer remains fast. The existing detection benchmark reports p99 6.23 ms. The new secured LangGraph invocation benchmark reports p99 32.72 ms for a compiled one-node graph with ProofLayer before/after checks enabled. Both are under the v0.2.0 sprint budget of 100 ms p99.

## Examples

The release includes five runnable examples:

- simple RAG with prompt-injection blocking
- tool-calling agent with allowlists and argument inspection
- multi-agent supervisor with state monitoring

Run them locally:

```bash
python examples/integrations/langgraph/01_simple_rag.py
python examples/integrations/langgraph/02_tool_calling_agent.py
python examples/integrations/langgraph/03_multi_agent_supervisor.py
python examples/integrations/langgraph/04_memory_attack_demo.py
python examples/integrations/langgraph/05_production_template.py
```

## What Comes Next

LangGraph is the first first-class agent framework integration. The same package structure can support CrewAI, AutoGen, and other agent frameworks later while preserving one canonical ProofLayer rules engine.

For teams shipping LangGraph agents into production, v0.2.0 gives them a security layer they can run locally, inspect, test, and extend.
