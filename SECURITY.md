# Security Policy

## Supported Versions

We support security updates for the latest minor release.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in ProofLayer's runtime rules layer, please report it responsibly.

**Do not open a public GitHub issue.**

Email: `founders@sinewaveai.com`

Please include:

- A description of the vulnerability
- Steps to reproduce
- Affected version(s)
- Impact assessment if available

We commit to:

- Acknowledging your report within 48 hours
- Providing an initial assessment within 5 business days
- Coordinating responsible disclosure with you before public release

We do not currently run a bug bounty program but are happy to credit reporters in release notes upon request.
